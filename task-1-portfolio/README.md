# Personal Portfolio — Task 1

A responsive portfolio site made with HTML, CSS, and a small amount of JavaScript. It includes a header, About section, illustrated profile image placeholder, Skills, Projects with visual previews, Resume download, Contact details, and footer.

## Run it

Extract the ZIP and open `index.html` in a modern browser. No installation or build step is needed.

## Personalize before submitting

Replace `[YOUR NAME]`, `[Your Name]`, `[YOUR CITY]`, and the example email and phone details in `index.html`. Replace `profile.svg` with a suitable photo you have permission to use, keeping the filename `profile.svg` or updating the image path. Review the skills and project cards so they accurately reflect your own work. Replace `resume.pdf` with your real resume PDF before sending this portfolio to an employer; the included file is only a starter template.

## Files

- `index.html` — page sections and editable portfolio content
- `style.css` — responsive visual design
- `script.js` — mobile navigation and current year
- `profile.svg` — replaceable illustrated profile image placeholder
- `resume.pdf` — starter resume PDF; replace it with your own resume

External Google Fonts are optional. System fallbacks keep the page usable offline.
